ESOL Speaking & Listening Placement Interview (E1–L2)

A spoken placement interview run by Claude. The learner wears headphones and talks to it directly; it ends with an approximate ESB level.

⚠ Teachers only – not for learners This page is not a test learners can sit on their own. Running it needs a teacher with a Claude account, signed in on the classroom machine, with the project open in voice mode.
  • Learners must never open the interview themselves – they would see the questions, the levels and other learners' results.
  • Results and feedback are released only to the teacher, on asking.
  • Vary nothing by hand: the interview changes itself between learners so the next one in the room can't copy answers.

How to run it

  1. Open the ESOL project in Claude on the classroom machine and turn on voice mode.
    Open the ESOL project in Claude ↗
  2. Say or type: run the speaking placement test
  3. Put headphones and a microphone on the first learner. Sit them where the rest of the class can't hear the questions.
  4. The learner says Hello, I'm here and the interview begins. It asks one question at a time and lasts about five minutes.
  5. It finishes with Thank you, that's the end of the test and asks the learner to fetch the next student. Then it stays quiet until the next learner says Hello, I'm here.
  6. No result is read out in front of the learner. To see the results table, say This is the teacher.

What it covers

RangeESB ESOL Skills for Life, Entry 1 to Level 2+
LengthAbout 5 minutes per learner; it stops early once the level is clear
SkillsSpeaking and listening. One listening text, returned to later with different questions, with a plain spoken explanation before the first listening item
ResultAn approximate level per learner, plus two or three sentences of feedback. Ask for the full breakdown if you want it
RecordsA results table per class, shown in the chat to the teacher on request

Before the first learner

  • Test the microphone and headphones. A room where others can overhear defeats the point.
  • Have the class list to hand – each learner gives their name at the start.
  • Give the rest of the class something to get on with: this runs one learner at a time.

SMART targets can be generated from the same results in the project afterwards.
