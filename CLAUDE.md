# ESOL Library – rules for adding or changing materials

The home page (`index.html`) and `README.md` are GENERATED. Never edit them by hand.

To add, rename or remove anything in the library:
1. Put the file in `<level>/<skill>/` (online pages) or `<level>/<skill>/docs/` (Word + PDF with the same name).
2. Add an entry to the lists (optional `week` number puts it in teaching order; otherwise taken from a `wkNN-` file name or "Wk N" in the title) in the AtinWix/personal repo: `tools/esol.json` for online pages (id, folder, path, title, note, claude) or `tools/docs.json` for Word documents (folder, path, title).
3. Copy `esol.json`, `docs.json` and `logo.html` to `/home/claude/build/` (or fix the paths in the script), then run `python3 <personal>/tools/home.py`. It rebuilds `index.html` and `README.md`, including the "Report a problem" links (they email Atin via `r.html`).
4. If home.py stops with "items are on the library page but missing", add those items to the lists – never use `--force` unless Atin asked for them to be removed.
5. Commit and push BOTH repos (esol and personal), so the lists and the page stay in step.
6. Public materials live ONLY in the library: don't also publish them as separate Claude artifacts. Claude artifacts are only for private tools (Lesson Log, Lesson Ideas, Smart Targets, Teacher Hub, AI marker). In `esol.json` the `id` and `claude` fields may be empty.
7. Add the lesson day to Atin's Teacher Hub: ArtifactData "set" on https://claude.ai/artifact/Ko1Xu9t4cmaH4Hc9kYWa4q, collection "upcoming", doc_id "<YYYY-MM-DD>_<class key e1|e2|e3>", data {date, cls, title, morning, afternoon, print, prep, links:[{label,url}]} (https links only). The old ESOL Materials Catalogue artifact is retired – do not update it. The Teacher Hub is Atin's private daily plan. Do NOT recreate a public Coming Up page or `coming-up.json` in AtinWix/esol – his plans must not be in the public library (removed 5 Nov 2026).
8. Lessons made in ANY chat (not just the scheduled builds) must be filed this way the same day: library + lists + home.py, Teacher Hub card, the Record of Work snippet in `teaching/row-snippets.md` (personal repo), "Next" in `teaching/classes-2026-27.md`, and the Lesson Log "planned" entry (ArtifactData "set" on https://claude.ai/artifact/9hm8WZXWiu3U16Cxxq32NK, collection "planned", doc_id "<YYYY-MM-DD>_<e1|e2|e3>", data {date, classKey, am, pm}). Projector material goes in as a 16:9 HTML page (a .pptx may be added as well). If a chat cannot reach GitHub, it uploads every file plus a `manifest.json` ({date, classKey, title, morning, afternoon, print, prep, rowSnippet, files:[{name, label}]}) to the Google Drive folder "ESOL Library Inbox" (id 17RIrftq9FJszFRjsCDhpGC8cx8nu1Ewu), in a subfolder named "<YYYY-MM-DD>_<e1|e2|e3>"; the 2:35pm task files it.
9. Before building any lesson day, check it hasn't already been made elsewhere: a day plan or ROW snippet in the repos, a Teacher Hub card, a subfolder in the Drive inbox, or a calendar event "Lessons <day>" marked ready. If it has, file that instead of rebuilding.
10. Changes count too: whenever filed material is updated or corrected in any chat, replace it in the library the same turn (same path, regenerate the matching PDF, run home.py if a title or path changes) and update the Teacher Hub card, ROW snippet and Lesson Log entry if they are affected. A changed file handed over only in chat is not filed.
