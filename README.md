# ESOL Library

Online ESOL activities, projector lessons and games, Entry 1 to Level 2. Made by Atin.

Live site: https://atinwix.github.io/esol/

Each level has three strands: Reading, Writing, Speaking & Listening. Pages marked *Uses Claude live* need the Claude version for their AI part.
